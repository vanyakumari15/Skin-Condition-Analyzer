# 🚀 Quick Start Guide

## Getting Started in 3 Minutes

### Step 1: Start the Server ✅
The server is already running at: **http://127.0.0.1:5000**

If you need to restart it:
```bash
python app.py
```

### Step 2: Open Your Browser 🌐
Navigate to: **http://localhost:5000**

### Step 3: Create an Account 👤

1. Click **"Get Started Free"** or **"Sign Up"**
2. Fill in the registration form:
   - Username: Choose any username
   - Email: Enter your email
   - Password: At least 6 characters
3. Click **"Create Account"**
4. You'll see a success message

### Step 4: Login 🔐

1. Click **"Login"** (or you'll be redirected automatically)
2. Enter your username and password
3. Click **"Login"**
4. You'll be redirected to the analysis page

### Step 5: Analyze a Skin Condition 🔬

**Option A - Upload an Image:**
1. Click the upload area or drag & drop an image
2. Wait for the preview to appear
3. Click **"Analyze Image"**
4. Wait a few seconds for processing

**Option B - Capture a Photo:**
1. Click **"Capture Photo"** button
2. Allow camera access when prompted
3. Position your camera
4. Click **"Capture"**
5. Click **"Analyze Image"**

### Step 6: View Your Report 📊

1. Automatically redirected to the report page
2. See your results:
   - Primary diagnosis (highlighted in green)
   - Top 3 possible conditions
   - Confidence percentages
   - Detailed descriptions

### Step 7: Download PDF Report 📄

1. Click **"Download PDF Report"**
2. Wait for generation (a few seconds)
3. PDF will download automatically
4. Open and review your report

### Step 8: Analyze Another Image 🔄

1. Click **"New Analysis"** button
2. Upload/capture another image
3. Repeat the process

## 🎯 Quick Tips

### For Best Results:
- ✅ Use good lighting
- ✅ Keep camera steady
- ✅ Focus on the affected area
- ✅ Include some healthy skin around it
- ❌ Avoid blurry images
- ❌ Avoid very dark photos

### Supported Image Formats:
- JPG / JPEG
- PNG
- Max size: 10MB

### Browser Recommendations:
- Chrome (best for camera)
- Firefox
- Safari
- Edge

## 🆘 Troubleshooting

### Server Not Running?
```bash
python app.py
```

### Can't Access Camera?
- Check browser permissions
- Use HTTPS in production
- Try uploading an image instead

### Login Not Working?
- Check username/password
- Make sure you registered first
- Try registering a new account

### Analysis Taking Too Long?
- Wait up to 10 seconds
- Check your internet connection
- Refresh and try again

### PDF Not Downloading?
- Check browser download settings
- Allow pop-ups if blocked
- Try a different browser
